## Current position

Local task contract/registry, fixed validation executor, strict typecheck, and pure payment transition model are implemented. Domain model is a proposed state graph and evidence-label contract, not provider-validated policy or a production payment authority. No API, database, idempotency persistence, provider adapter, webhook verifier, ledger, or financial operation exists. OpenCode has not run a coding task and no remote model request was sent. The local registry remains single-process prototype state, not a secure queue or OS sandbox. OpenCode remote dispatch remains blocked pending trusted provider/auth/cost confirmation and safe isolation.
